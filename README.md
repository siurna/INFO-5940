# Document Chat (RAG App) for Assignment #1

Retrieval-Augmented Generation app built with **Streamlit**, **LangChain**, and **Chroma**, using the **Cornell AI Gateway (OpenAI-compatible)**.  
Upload `.txt` or `.pdf` files, get an automatic summary, and chat with your documents.

---

## How to run

```bash
streamlit run ts942_chatbot.py
```
